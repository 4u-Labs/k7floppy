📖 Manual Oficial — Microdigital TK 2000 II (Emulador Real 6502)

🧠 Programando em TK-BASIC (ROM Real)

  • Você está na ROM original de 16KB em Português do TK 2000!
  • Gráficos Hi-Res: 10 HGR : HCOLOR= 3 : HPLOT 0,0 TO 279,191
  • Som no alto-falante: SOUND 20, 15 (nota 1–60, duração)
  • Monitor / Assembly: CALL -151 (ou @ conforme ROM)
  • Interromper programa: CTRL + C

💾 Gravando seus Programas em Fita K7!

  1. Escreva seu programa em BASIC (ex: 10 PRINT "OI").
  2. Clique em ● REC no gravador K7 à esquerda e dê um nome (ex: MEU).
  3. Digite no TK 2000: SAVE T "MEU" e aperte ENTER.
  4. Quando voltar o prompt ], clique em ■ STOP no gravador.
  5. Sua fita fica salva no navegador (e você pode baixar o arquivo .CT2)!
  6. Para carregar depois: clique na fita, digite LOAD T "MEU" + ENTER e depois aperte ▶ PLAY (ou use ⚡ Auto-Load).

🕹️ Rodando Jogos Originais (Karateka, Choplifter, etc.)

  • O emulador roda CPU 6502 real e lê fitas originais nos formatos .CT2 e .WAV.
  • Por direitos autorais, jogos comerciais da época (como Karateka da PlanSoft/Brøderbund) não vêm pré-embutidos, mas você pode baixar o .CT2 ou .WAV em acervos de preservação (como Datassette, OldPlayers ou Internet Archive) e arrastar direto para o gravador K7 ou clicar em 📂 Abrir .CT2 / .WAV!
  • Dica para o Karateka: após carregar a fita (com LOAD T ou LOAD A + ▶ PLAY), ligue a chave 🕹️ Joystick ($C064) à direita se quiser jogar com as Setas + Espaço!
  • Fitas K7 já prontas no rack: clique em Arte HGR, Adivinhe, Piano TK ou Labirinto HGR e clique em ⚡ Auto-Load — você pode dar LIST para ver e editar o código BASIC real!

📘 Manual do BASIC — Microdigital TK 2000 II (Referência da ROM)

1. Edição, Execução & Sistema

  • NEW — Apaga o programa atual da memória.
  • LIST / LIST 10,50 — Lista todas as linhas ou de 10 a 50.
  • RUN / RUN 100 — Executa o programa (ou a partir da linha 100).
  • CONT — Continua execução após STOP ou CTRL+C.
  • DEL 10,30 — Apaga linhas de 10 até 30.
  • CLEAR — Zera todas as variáveis e arrays.
  • REM texto — Comentário ignorado na execução.
  • STOP / END — Encerra ou pausa o programa.
  • CALL -151 — Entra no Monitor (Linguagem de Máquina).
  • ASS — Entra no Mini-Assembler da ROM.
  • FRE(0) — Mostra a quantidade de memória RAM livre.

2. Entrada, Saída & Texto

  • HOME — Limpa a tela e posiciona o cursor no topo.
  • PRINT expr (ou ?) — Imprime texto/números; use ; para continuar na mesma linha.
  • INPUT "NOME:"; A$ — Lê texto ou número com ENTER.
  • GET A$ — Lê 1 tecla pressionada imediatamente (sem ENTER).
  • HTAB 1..40 / VTAB 1..24 — Move cursor para coluna/linha.
  • TAB(n) / SPC(n) — Tabulação ou n espaços no PRINT.
  • INVERSE / NORMAL — Texto invertido (fundo claro) ou normal.
  • TEXT — Retorna do modo gráfico para o modo texto.
  • SPEED= 0..255 — Controla velocidade de impressão na tela.
  • POS(0) — Coluna atual do cursor.

3. Gráficos Hi-Res (280×192) & Formas

  • HGR / HGR2 — Ativa tela gráfica Hi-Res (página 1 ou 2).
  • HCOLOR= 0..7 — Define cor de desenho (0=Preto, 1=Verde, 2=Violeta, 3=Branco, 5=Laranja, 6=Azul).
  • HPLOT X,Y — Plota um ponto em (X,Y), X=0..279, Y=0..191.
  • HPLOT X1,Y1 TO X2,Y2 — Traça linha contínua (pode encadear vários TO).
  • DRAW n AT X,Y / XDRAW n AT X,Y — Desenha shape n (ou XOR para apagar/animar).
  • ROT= 0..63 / SCALE= 1..255 — Rotação e escala dos shapes.
  • GR / COLOR= / PLOT / HLIN / VLIN — Comandos gráficos herdados na tabela de tokens.

4. Som & Fita K7 (Exclusivos TK 2000)

  • SOUND nota, dur — Toca nota no alto-falante interno (ex.: SOUND 20, 15).
  • SAVE T "NOME" — Grava o programa BASIC em fita K7 com nome (clique ● REC antes).
  • LOAD T "NOME" — Carrega programa nomeado da fita K7 (ou LOAD T para o próximo).
  • SAVE A / LOAD A — Grava/lê fita no formato Apple II sem cabeçalho de nome.
  • LM — Carrega código de máquina da fita.
  • MOTOR / SHLOAD — Controle do motor do K7 / carga de tabela de shapes.

5. Controle de Fluxo, Laços & Dados

  • LET X = 10 (ou X = 10) — Atribui valor a uma variável.
  • IF cond THEN cmd — Execução condicional (=, <>, <, >, AND, OR, NOT).
  • GOTO 100 — Salta diretamente para a linha 100.
  • GOSUB 500 / RETURN — Chama sub-rotina e retorna.
  • POP — Descarta o último endereço de retorno do GOSUB.
  • FOR I=1 TO 10 STEP 2 ... NEXT I — Laço de repetição.
  • ON X GOTO 10,20,30 / ON X GOSUB ... — Desvio múltiplo por índice.
  • DIM A(10,10) — Dimensiona vetores/matrizes.
  • DATA ... / READ X / RESTORE — Lê dados embutidos no código.
  • ONERR GOTO 900 / RESUME — Tratamento de erros em execução.

6. Funções, Hardware & Erros da ROM

  • Matemática: ABS, INT, SGN, SQR, RND(1), SIN, COS, TAN, ATN, LOG, EXP, DEF FN.
  • Texto (Strings): LEN(S$), LEFT$(S$,n), RIGHT$(S$,n), MID$(S$,i,n), ASC(S$), CHR$(n), STR$(n), VAL(S$).
  • Memória & Joystick: PEEK(e), POKE e,v, PDL(0) (eixo X), PDL(1) (eixo Y), PEEK(49249)>127 (botão fire).
  • Erros da ROM: SINTAXE ERRO, VALOR ILEGAL, DIVISAO POR ZERO, NEXT SEM FOR, RETURN SEM GOSUB, INDICE ILEGAL, ESTOURO, EXCEDE MEMORIA.

🍎 Manual de Operação — Apple II+ & Disk II

💿 Como Usar Disquetes (.DSK / .DO / .PO)

  • Clique em qualquer jogo da lista DISQUETES 5¼" à direita para inserir e dar boot automático.
  • Você também pode clicar em 📂 Abrir .DSK ou arrastar qualquer imagem .dsk (140 KB) do seu computador para a tela.
  • Se estiver no prompt ] do Applesoft BASIC com um disco inserido, digite PR#6 + Enter para dar boot pelo Slot 6.
  • Pressione Shift + Esc (ou clique na trava do drive) para ejetar o disco.

🕹️ Joystick, Teclado & Jogos

  • Jogos de arcade/ação ativam o Joystick ($C064/$C061) automaticamente: use as Setas, Espaço (Botão 0) e Alt (Botão 1).
  • Em jogos com opção de teclado (como Karateka ou Moon Patrol), pressione K no jogo para usar o teclado (e J para voltar ao joystick).
  • O painel TECLAS à direita exibe automaticamente os comandos exatos de cada jogo instalado.

⌨️ Comandos DOS 3.3 & Monitor

  • CATALOG — Lista os arquivos do disquete DOS 3.3.
  • RUN NOME — Carrega e executa um programa BASIC do disco.
  • BRUN NOME — Carrega e executa um binário em código de máquina.
  • CALL -151 — Entra no Monitor de Sistema (prompt *). Digite 3D0G + Enter para voltar ao BASIC.

📘 Manual Applesoft BASIC (Apple II+)

1. Edição, Execução & Tela Texto

  • HOME — Limpa a tela de texto (40×24) e move o cursor ao topo.
  • LIST / LIST 10,50 — Lista as linhas do programa em memória.
  • RUN / RUN 100 — Executa o programa desde o início ou da linha 100.
  • NEW — Apaga o programa atual da memória.
  • PRINT expr (ou ? expr) — Exibe texto ou cálculo na tela.
  • INPUT "NOME? "; N$ — Solicita entrada de dados ao usuário.
  • HTAB x / VTAB y — Posiciona o cursor na coluna x (1–40) e linha y (1–24).
  • INVERSE / NORMAL / FLASH — Alterna texto invertido, normal ou piscante.
  • Ctrl + C — Interrompe a execução do programa (BREAK).

2. Gráficos Lo-Res (GR) & Hi-Res (HGR)

  • TEXT — Retorna do modo gráfico para texto completo 40×24.
  • GR — Ativa modo gráfico de baixa resolução (40×40 + 4 linhas de texto).
  • COLOR= c — Define cor Lo-Res (0 a 15).
  • PLOT x, y / HLIN x1,x2 AT y / VLIN y1,y2 AT x — Desenha ponto e linhas em Lo-Res.
  • HGR / HGR2 — Ativa Hi-Res (280×160 + texto na página 1, ou 280×192 tela cheia na página 2).
  • HCOLOR= c — Define cor Hi-Res (0=Preto, 1=Verde, 2=Violeta, 3=Branco, 5=Laranja, 6=Azul).
  • HPLOT x, y / HPLOT TO x2, y2 — Desenha pontos e segmentos de reta em Hi-Res.

3. Controle de Fluxo, Hardware & Disco

  • IF cond THEN cmd / GOTO n / GOSUB n / RETURN — Desvios e sub-rotinas.
  • FOR I = 1 TO 10 STEP 2 ... NEXT I — Laço de repetição.
  • DIM A(10) / DATA ... / READ X — Vetores e dados embutidos.
  • PEEK(addr) / POKE addr, val — Lê ou grava direto na RAM/I/O (ex: PEEK(-16336) gera clique no alto-falante).
  • PDL(0) / PDL(1) — Lê os eixos X/Y do Paddle/Joystick (0–255).
  • PR#6 / IN#0 — Redireciona saída para o Slot 6 (Disk II) ou entrada padrão.
  • CALL -151 — Entra no Monitor hexadecimal da ROM.
